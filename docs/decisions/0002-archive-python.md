# 0002 旧 Python 版归档到单独分支

状态：已决定（2026-10-03）。下面说的功能分支怎么用，后来改成了 [0003](0003-github-flow.md)。

## 背景

旧 Python 版（Tkinter + Matplotlib）已经冻结，不再加功能（见 [0001](0001-platform.md)）。
新的 Godot 原型放在同一个仓库里以后，两套代码混在一起，容易看错、改错。

## 决定

- `archive/python` 分支：只有旧 Python 版，留作归档，几乎不再用。
  需要对照旧规则时，切到这个分支看。
- `master` 分支：只有 Godot 版（`game/`）和共享文档，以后都在这里开发。
  大的改动可以先在功能分支上做（例如 `feature/prototype`），做完合并回 `master`。
- 两个分支不再合并。旧 Python 版的 bug 不修，新版本避开：
  - 隐藏文明发出的二向箔打不中目标。
  - 发射者灭亡后，它的二向箔停在原地。

## 理由

- 主分支只剩一套代码，新加入的人不会搞混。
- 旧代码不删历史，随时能找回，也能继续打包运行。
- 旧规则已经整理进 [设计说明](../design/game-design.md) 和
  [交接文档归档](../design/archive/handoff-2026-10-03.md)，平时不用看旧代码。
