## 当前实现：自身降维的携带成本（2026-10-04）

目标：所有现有单位一起降维，已建成设施也计入携带费用；多回合准备和建造限制在规则、AI 与界面中一致。
沿用暂定数值：基础 10E，每单位 5E，准备 3 回合。暂不增加部分携带选择。

- [x] 完善计数：星系、飞船、设施和库存反物质各计一单位；每次完成的望远镜 / 探测器升级计一单位。
- [x] 防止漏计：已有建造 / 升级订单必须完成后才能开始降维；拒绝操作不扣资源或行动点。
- [x] 操作反馈：显示携带明细和费用公式、剩余回合；准备期间禁止建造、派新飞船和投放黑域 / 降维箔。
- [x] 验证规则测试、场景回归、原生鼠标操作及 AI 模拟，同步设计、现行规则和开发日志。
- [x] 分步提交，验证后干净合并回主工作区。
- [ ] 清理临时 worktree：归档被固定聊天 / 工作区保护阻止，已保留干净的 `codex/reduction-costs` worktree。

完成标准：已建成单位增加时费用正确上涨；不会提前完成降维或在准备期间新增建造；
不足资源、重复启动、有未完成订单均不产生扣费；二维至一维沿用同一规则；界面与规则一致。

验证结果：101 个规则测试、1268 项原生场景检查（含截图保存）通过；鼠标实际完成建造、
费用上涨、三回合准备、禁用建造和完成后恢复。50 局 AI 模拟无脚本错误，数值仍待试玩。
集成完成：`c63192b`、`75b4fd5`、`07de583` 已通过 fast-forward 合并回 `master`。
本次测试进程和临时 QA runtime 副本已清理。worktree 归档工具返回

## 当前修复：降维打击完成性（2026-10-04）

目标：二向箔最终把整张坐标网格压到同一平面；战斗结束不能截断已展开的空间坍缩。

- [x] 规则和回归测试：第一次展开确定共同平面，后续打击沿同一平面扩散；
  一次扩散完整结算，胜负出现后仍能完成环境坍缩。
- [x] 画面和交互：展示完整压平过程，结束后的坍缩继续播放，网格、边界和单位位置一致。
- [x] 验证：原有规则测试、不同高度的多次打击、提前结束、原生 Godot 画面；同步规则和开发日志。
- [x] 已确认：二维继续游戏、自身再次降维、单向箔把平面压成沿 x 轴的直线。
  第一片箔确定共同平面 / 直线；沿用 30E、2 回合准备和每回合 1 格的飞行；
  再次自身降维沿用原有成本和 3 回合准备，产出再减半；全图成为直线后才判平局。

完成标准：多次打击后只剩一个共同平面；提前胜负不留下半截立体空间；
回归测试通过，原生画面核对完成，分步提交并干净合并回主工作区。

验证结果：97 个规则测试、原生场景回归和鼠标操作均通过；50 局 AI 模拟无脚本错误。
