# 要确定的问题

规则以[当前 V0.1](design/current-rules.md)为准，旧问题原文见[存档](design/archive/open-questions-before-v01.md)。测试和模拟结果只记在[现状](status.md)。

## 尚待试玩证据

### E1. 文明越滚越大，对局打不完

目标仍是容易开始、持续有操作、普通战术有用，并在 400 回合观察窗口内产生合法终局。当前不能用测试通过或纯 AI 胜率证明达到真人目标。

- 选项 A：先按冻结版本取得三路线六局证据，再调整少量参数。
- 选项 B：在没有可比较证据时继续调整科技和终局。
- 推荐 A。III 的严格侦察确认是否自然可达需单独报告；不以全知裁定绕过。

新来源：[消息 381](proposals/chat-direction-sources.md#广播路线行动点与殖民限制)提出限制殖民星系总数，原因还包括人类玩家难以管理。当前没有殖民星系总数上限；可以作为候选与殖民维护一起比较，具体上限等试玩，母星、星舰和被打掉后重新殖民是否计数一起明确。殖民地行动点见 E15。

### T24. 战舰带反物质

当前炸弹按共同发射源、已收目标和有限传播造成物理伤害，星舰已有耐久。通用战舰的独立反物质装载、补给与自动开火不在当前模块表中。

- 选项 A：保持现有炸弹入口，待完成 V0.1 验收后单独设计舰载补给。
- 选项 B：新增通用战舰弹药装载与自动开火流程。
- 推荐 A，避免在本次验收中扩充机制。

### E17. 一维是否需要小地图或全线导航

来源：[消息 113～119](proposals/chat-direction-sources.md#本轮补出的讨论与后续消息)。E7F6 在一维长线截图后问要不要加小地图，没有定。一维镜头定位、拖动和方向操作已经有了，缺的是全线概览。

- 选项 A：沿用当前镜头，先记录玩家是否经常找不到自己的锚点或威胁。
- 选项 B：加一维小地图，标出已知锚点与已收到的威胁，可以跳转镜头。
- 选项 C：用全线概览或锚点跳转代替小地图。
- 推荐 A，确有导航困难再比较 B、C。概览也只显示已收到的信息。

## 现在可以回答

### E15. 母星与殖民地的行动点分配

来源：[消息 366、377～380](proposals/chat-direction-sources.md#广播路线行动点与殖民限制)。E7F6 反对所有文明固定行动点，提出按单、双、三星母星与殖民地分配，并举母星 4/3/2、殖民地 3/2/1 的例子；ccl 说下一版测试，数值没定。

当前每文明每年固定 3AP，原母星另有 2 个建造槽（W6）；殖民地不按恒星数贡献行动点。

- 选项 A：保持固定 3AP 和双建造槽。
- 选项 B：按群聊举例设母星和各殖民地贡献，再试玩调整。
- 选项 C：按同样方向设贡献，同时设全文明行动点上限。
- 推荐 C 作为实验方案，和 E1 的殖民上限一起看人类玩家的管理负担。还要明确原母星被毁、只剩掩体或星舰、同年殖民或失地时的行动点，避免无法恢复。

### E16. 空间变化的可见范围和黑域

来源：[新增讨论](proposals/feedback-latest-discussion.md#空间变化全局可见)（消息 662、711、712）。E7F6 说二向箔在视野外飞行看不到，但展开带来的空间变化全图都看得到；死线和黑域不阻挡二向箔，降维后一起清除。

当前已展开的前沿只能靠自己的传感器看到并回传，这一点和上面的说法不符。前沿按当前维度背景光速的 0.5 倍扩散，本来就不受黑域减速，和「不阻挡」相符。

- 可见：A 全图立即看到空间变化；B 全图都能看到，但按光速传到才看到；C 保持只靠视野。
- 黑域：A 保持现状，前沿不受黑域影响；B 改成经过黑域时按当地光速变慢。
- 推荐可见选 B、黑域选 A。还要定：空间变化从什么时候开始显示，自己的损失怎样报告，死线是否也不阻挡前沿。

### E18. 十年一回合的尺度

来源：[消息 638～664](proposals/feedback-latest-discussion.md#十年一回合的尺度调整)、[644～649](proposals/feedback-latest-discussion.md#位置精度当地光速与到达)。E7F6 提出一回合代表十年，每格仍是一光年；光速就是每回合 10 格，普通推进上限 0.15 倍光速是每回合 1.5 格。消息 663 确认的是方向，具体数值没定。同时提出位置和速度只保留到 0.01，每回合按起点格子的当地光速算能走多远。

- 选项 A：改成十年一回合，工期、速度、传播、维护、冷却和扩散一起重算，旧存档和回放不再兼容。
- 选项 B：保留一年一回合，只把每回合能做的事调多。
- 选项 C：先在一个数值方案里试十年尺度，试玩后再决定。
- 推荐 C。要一起定的是：低维格距、各船型速度和工期、资源按年还是按回合算，以及位置舍入、格子边界和一步穿过几个不同光速格子时怎么算。

### E19. 光粒的命中宽度和空星系遮挡

来源：[消息 650～655](proposals/feedback-latest-discussion.md#光粒的命中与预警)。E7F6 希望光粒的打击范围明显变窄（举例 0.05），已知目标打得中、盲射多半打空；光粒沿路先碰到没人住的星系时，在那里毁掉一颗恒星并用掉自己；预警范围要够大，留出造掩体的时间。

当前光粒按物理半径扫掠，只打沿途合格的敌方恒星，空星系不挡。

- 选项 A：按上面的方向改，宽度和预警范围试玩时调。
- 选项 B：只收窄宽度，不加空星系遮挡。
- 选项 C：保持现状。
- 推荐 A。要确认：宽度是半径还是直径；同一回合碰到几个星系时的顺序；双星、三星毁哪一颗；有掩体的星系保留什么。

### E20. 资源整数结算与维护

来源：[消息 475～548](proposals/feedback-latest-discussion.md#资源整数结算与维护)。试玩时资源显示小数、维护只有零点几，能不能付得起看不明白；ccl 倾向不再做连续资源结算。

当前库存按千分之一资源记账、连续结算，维护单独扣。

- 选项 A：资源按回合整数结算，显示多少就能付多少。
- 选项 B：内部保留小数，界面取整。
- 选项 C：维护折进净产出，不单独显示。
- 推荐 A，可以和 C 一起用。B 会出现「显示 1、实际 0.9 付不起 1」。要确认余数怎么处理、低维产出倍率、资源不够时怎样休眠。
