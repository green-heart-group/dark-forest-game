## 运行与验证

在仓库根目录运行（终端里的 `godot_console` 可替换为本机 Godot 可执行文件的完整路径）：

```bash
godot_console --headless --path game --import
godot_console --path game res://demos/dimension_unfolding.tscn
godot_console --headless --path game --script res://tests/run_unfolding_tests.gd
```

默认暂停，先显示单列；选择「全图」查看整个波前。锚点的 x、y、z 使用 0～8，方块上的 1～9 是原 z 层编号。
支持播放、暂停、重播、前后拖动进度、0.5 / 1 / 2 倍速、左键旋转、滚轮缩放、俯视与重置。
关闭「自动取景」可固定相机位置和取景范围；仍可以手动旋转和缩放。快捷键为空格、左右方向键、R、T、V；
在坐标输入框中打字时不触发快捷键。

保存截图：去掉 `--headless`，在测试命令末尾加 `-- output=/绝对路径/截图目录`。
测试会保存单列和全图的 0 / 35 / 65 / 100% 帧、全图俯视、角落打击。

## 实现边界

- `game/demos/unfolding_layout.gd`：可逆的整数映射和确定性的波前布局；固定的是首个打击点，
  其他列中心随行列宽度的扩张移动。每一行 / 列的预留宽度取其所有格子需要空间的最大值。
- `game/demos/dimension_unfolding.gd`、`.tscn`：复用一个 MultiMesh 更新方块位置和厚度，
  相机按当前包围盒取景，数字在屏幕上保持可读大小。曲线路径先向外移动、后压平。
- 保留的是演示格子身份，尚未迁移真实星系、飞船、光速或情报数据。只有一个打击源。
- 未加入二维到一维、战斗存活判定、情报重置或 AI 政策；需要另行设计后接入规则。
