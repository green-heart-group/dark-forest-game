# 操作说明

玩游戏时怎么看星图、点选、存档和用快捷键。运行方法见仓库根目录的 [README](../../README.md#快速开始)，规则见 [原型现在的规则](../design/current-rules.md)。

## 看和选

- **看星图**：左键拖动旋转，滚轮缩放；也可以用键盘平移、旋转（星图左上角「视角操作」里有说明）。
- **选目标**：单击星图上的东西选中它；单击空处可以瞄准那一格。点不准时，在面板里直接输入 x、y、z 坐标。
- **科技树**：科技页打开独立全屏界面，前置科技在左、后续在右，箭头表示直接依赖；选节点查看说明和开放条件，再按研究。

## 星图层次

图例和全体视野默认收起。概览保留星系、全部飞行单位和敌情，停泊单位合并显示数量；悬停看具体种类、设施和情报，
选中或在行动页选择单位后显示航线。「详细星图」展开全部航线与设施。广播只显示最近三条传播波前，每条一个圈，摘要保留实际条数。

## 存档与读档

桌面版自动保存每次操作和回合结束后的对局，重新打开时选「继续上次对局」。退出前再次保存；保存失败时保留窗口，可重试、返回游戏另存，或明确选择放弃。选择新开一局会替换自动存档，想保留多局时请手动保存。

星图左上角「保存」「读取」，或 Ctrl+S / Ctrl+O。存档为 `.forest` 文件，恢复保存时的回合和已经执行的操作；
较长读档显示进度，可按取消或 Esc，失败时保留当前对局。桌面版默认打开个人存档目录，网页版下载或上传文件。

## 面板、快捷键和界面大小

- 右上角按钮或 Ctrl+B 收起面板，竖屏自动收起。
- Alt+1 打开全屏科技树（Esc 返回），Alt+2～4 切页，Alt+左右方向键选行动，Ctrl+Enter 执行，Shift+Enter 结束回合。
  正在输入坐标或操作弹窗时不触发这些快捷键。
- 拖动窗口时界面跟着缩放；Ctrl + 加号 / 减号调整字的大小，Ctrl + 0 恢复。
- 回合状态旁边的「🔄 重开」随时可以换一张新星图，或者在同一张星图上从头打。
