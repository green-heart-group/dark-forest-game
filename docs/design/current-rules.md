# 原型现在的规则（2026-10-03）

这份文档记录 Godot 原型**现在实际怎么运行**，方便合作者对照试玩。
目标设计以 [game-design.md](game-design.md) 为准；还没定的问题见 [待讨论](../open-questions.md)。

所有数值都在 `game/rules/balance.gd`，大部分是暂定的，可以边玩边调。
下面写的「E」是能量，「M」是矿石，「AP」是行动点。

## 1. 星图和星系生成

- 星图是 10×10×10 的格子，坐标 (x, y, z) 都是 0 到 9，右手系，z 朝上。一格大约 1 光年见方，
  最多放一个星系。
- 每个格子按顺序决定（E7F6 的设想）：
  1. 有没有星系：55%。
  2. 有几颗恒星：单星、双星、三星按 6:3:1 抽。
  3. 有几颗行星：单星 0～8 颗，双星 0～5 颗，三星 0～3 颗，范围内随便取。
     恒星越多，轨道越不稳定，行星越容易被吞掉，所以越少。
  4. 每颗行星一半机会是类地行星（固体），一半是类木行星（气体）。
  5. 每颗类地行星有 10% 宜居。有一颗宜居，这个星系就能殖民。
- 按这些概率，大约 550 个格子有星系；其中约 15% 能殖民（约 80 个），约七成有类木行星
  （能建掩体）。
- 开局时，你和 4 个 AI 文明的母星都随机放在能殖民的星系上。另有 15 个「隐藏文明」放在没有星系的
  空格子里：看不见、打不到，只会对广播做出反应（见 §5 广播）。
- 星系的位置不公开。你只知道自己的星系，别人的星系要靠探测、打击或广播才知道。

## 2. 回合和资源

### 每回合的收入

| 资源 | 怎么算 |
| --- | --- |
| 能量 | 每个星系 2，再加每颗恒星 1（单星系 3、双星系 4、三星系 5）；每个戴森球再加 3 |
| 矿石 | 每个星系 2；每艘采矿船再加 2 |
| 行动点 | 6 减去恒星总数，最少 2。恒星越多，行动点越少（原著的「乱纪元」） |

- 开局有 25 能量、25 矿石。
- 自身降维以后，能量和矿石收入都减半（向下取整）。
- 星系全丢了、只剩星舰时：每回合只有 2 能量、1 矿石、2 个行动点。

### 一个回合里发生什么

你在自己的回合里用行动点做事（每个行动或建造都花 1 AP），然后按「结束回合」。之后按这个顺序结算：

1. AI 文明依次行动。
2. 所有在飞的战舰前进，再是殖民船前进。
3. 已经展开的二向箔扩散一圈，然后在飞的二向箔前进（到了就展开）。
4. 准备中的黑域、隐藏文明的打击、准备中的广播各前进一回合，到时间的生效。
5. 上回合下单的建造和升级完成（「下回合生效」指的就是这里）；降维进度加一。
6. 发收入，重置行动点，进入下一回合。

## 3. 星系的「血量」和伤害

### 血量

- 一个星系的血量就是它的**恒星数**：单星 1，双星 2，三星 3。
- 光粒或战舰每打中一次，这个星系少一颗恒星。恒星少了，能量收入跟着少；多出来的戴森球也没了
  （戴森球个数不能超过恒星数）。
- 恒星打光了，星系就丢了，上面的戴森球、采矿船、掩体一起没了。
- 星舰没有血量：被战舰撞上、或者被二向箔压到，就毁掉。

### 一次打击打中星系时，按这个顺序判断

1. 打击路线穿过黑域的边界：被挡住，什么都不发生（见 §4 黑域）。
2. 对方已经降维，而打过来的是光粒：没有效果。战舰照样有效。
3. 打过来的是战舰，对方存着反物质：用掉一个反物质，拦下这艘战舰。
4. 对方有预警系统：预警系统用掉，抵消这次打击（光粒、战舰都能抵消）。
5. 都没有：少一颗恒星。
   - 打掉的是最后一颗恒星、打过来的是光粒、这个星系有掩体：星系**不丢**，
     变成没有恒星的星系（人躲在类木行星背后活下来）。以后光粒再打这里，没有东西可毁；
     战舰打中就丢了。
   - 其他情况：星系丢了。

每次被打中（包括被挡下的）都算「被打过」，AI 会据此决定要不要躲进黑域、建掩体。

二向箔不走这套判断，它直接压平空间（见 §4 二向箔）。只有已经降维的文明能在压平后活下来。

## 4. 行动按钮

每个行动花 1 AP。要方向的行动，用两个圆盘调：「水平角」在同一高度的平面里转
（0° 朝 x 轴，90° 朝 y 轴），「俯仰角」往上为正。要具体位置的行动（二向箔、黑域、广播），
再加一个「离发射源多远」的距离。在星图上点格子，角度和距离会自动算好。

「发射源」可以选自己的任何一个星系，或者自己的星舰。

| 按钮 | 花费 | 效果 |
| --- | --- | --- |
| 🔭 探测 | 2E | 从发射源朝一个方向看，圆锥范围里别人的星系都会被发现（记进「已知坐标」）。圆锥长度开始是 3 格，张开的角度开始是 15°，都可以升级。看不到星舰，也看不穿黑域。 |
| ✨ 光粒 | 18E | 要先建恒星广播器。从发射源沿直线打出一根圆柱（长 5 格、半径 0.5 格再加半个格子，现在不能升级），打中路上**最近的**别人的星系，让它少一颗恒星（按 §3 判断）。自己的星系会被穿过。路上确认没人的格子记进「敌情记录图」。当回合就有结果。 |
| 🚀 战舰 | 6E + 6M | 从发射源出发，每回合飞 2 格，宽度和光粒一样，没有射程限制。碰到第一个别人的星系就打它（少一颗恒星，按 §3 判断），碰到别人的星舰就把星舰撞毁，然后战舰用掉。飞出星图就消失，碰到黑域边界被困住。比光粒便宜，但慢。 |
| 🌱 殖民船 | 12E + 12M | 从发射源出发，每回合飞 2 格，停在经过的第一个**没人占、能殖民、还有恒星**的星系，变成你的新星系。别人的星系直接飞过，不会暴露任何信息。飞出星图就消失。 |
| 📄 二向箔 | 30E | 见下面「二向箔」。 |
| 🕳️ 黑域 | 28E | 见下面「黑域」。 |
| 📢 广播 | 6E | 要先建恒星广播器或引力波发射器。指定任意一个格子（不能是自己的星系），准备 2 回合后公开。那里有别人的星系时：所有其他文明都知道这个坐标；附近的隐藏文明可能出手（见下面「广播和隐藏文明」）。 |
| 🛸 星舰移动 | 2E | 星舰朝一个方向移动，最远 4 格，停在路上最远的一个能停的格子（在星图内、不是别人的星系、没被压平、不穿过黑域边界）。 |

### 二向箔

- 不能在降维期间发射。目标要在星图内，不能是发射源、自己的星系、已经压平的格子。
- 先在发射源准备 2 回合，然后每回合飞 1 格，最后一步直接落在目标上。路上碰到别人的星系就提前展开。
- **展开后的形状**（E7F6 的建议和 RainZL 画的侧视图）：平面的高度就是展开那一格的 z。
  设离展开点的水平直线距离是 d，展开了 t 回合，x = d − t：
  - x ≤ 0 的地方：整列压到平面上。展开那一回合只有中心那一列，之后每回合这个圆的半径加 1。
  - x > 0 的地方：平面上下各只留 x² 格高的空间（系数 `FOIL_SQUISH`，暂定 1），更高、更低的格子被压没。
  - 所以同一列可能只剩平面附近的一段。侧面看，活着的空间像躺倒的沙漏：中间收成一个平面，
    两边张开。扩散不会停，最终整张星图只剩一个平面。
- 被压没的格子：
  - 没降维的文明在那里的星系丢掉，恒星消失；在那里飞的飞船被毁；星舰被毁。
  - 已经降维的文明活下来：星系和星舰移到同一列的平面上。平面上那一格已经有星系时，
    后移过去的那个算作毁掉。
  - 碰到压平格子的黑域消失。
- 压平的区域所有文明都看得到。发射者灭亡时，它准备中和在飞的二向箔也消失。

### 黑域

- 不能在降维期间投放。指定一个中心，离发射源不能超过自己的探测长度；准备 2 回合后，
  生成以它为中心、边长 3 格的立方体，永久存在（被二向箔压到时才消失）。所有文明都看得到。
- 光和飞船都不能穿过黑域的边界：
  - 一头在黑域里、一头在外面：挡住（外面打不进来，里面也打不出去）。
  - 两头都在外面，但直线穿过黑域：也挡住。所以黑域可以当「星际长城」，放在自己和敌人之间。
    对方可以从别的星系或星舰出发，换一条不穿过黑域的路线绕过来。
  - 两头都在同一个黑域里：不挡。
- 二向箔不受黑域影响。

### 广播和隐藏文明

- 广播的坐标上有别人的星系时，离这个坐标 6 格以内的隐藏文明可能出手。
  紧挨着的出手机会是 50%，越远越小，到 6 格时为 0。一次广播最多引来一次打击。
- 出手后 2 回合打到。90% 是光粒（按 §3 判断，但没有反物质这一步，也打不进黑域），
  10% 是二向箔（直接在那一格展开）。
- 这就是「借刀杀人」：自己不暴露，让别人去打。

## 5. 建造和升级

每项花 1 AP，**下一回合生效**。降维期间、或者没有星系（只剩星舰）时不能建造。
「建在星系上」的项目，建在面板上选中的发射源上。

| 按钮 | 花费 | 效果 | 限制 |
| --- | --- | --- | --- |
| 📡 射电望远镜 | 8E | 探测圆锥的张角 +10° | 最大 60° |
| 🛰️ 探测器 | 10M | 探测长度 +1 格（也决定黑域能投多远） | 最长 10 格 |
| 🚨 预警系统 | 10E | 抵消下一次光粒或战舰打击，用掉后可以再造 | 同时最多一个 |
| ⚛️ 反物质 | 6E + 4M | 存起来，每个拦下一艘打到自己任何星系的战舰。挡不住光粒 | 最多存 3 个 |
| 🌟 恒星广播器 | 6E | 有了才能发光粒和广播 | 每个文明一个 |
| 🌊 引力波发射器 | 4E + 4M | 有了才能广播（不能发光粒） | 每个文明一个 |
| ⛏️ 采矿船 | 4M | 这个星系每回合多产 2 矿石 | 每个星系一艘 |
| 🌞 戴森球 | 16M | 每个每回合多产 3 能量 | 每个星系最多和恒星数一样多；恒星被打掉，多出来的也没了 |
| 🛡️ 掩体 | 8E + 8M | 最后一颗恒星被光粒打掉时，星系不丢（见 §3） | 星系要有类木行星；每个星系一个 |
| 🛸 星舰 | 7E + 7M | 在这个星系建一艘星舰。星舰能移动，能当发射源；探测发现不了，光粒打不到；被战舰撞上或被二向箔压到就毁掉 | 每个文明一艘 |
| 🏠 星舰定居 | 免费 | 星舰停在没人占、能殖民的星系上时，在那里建立星系，星舰用掉。当回合生效 | 要有星舰 |
| 🔻 自身降维 | 10E + 5E × 单位数 | 3 回合后完成，期间不能建造。完成后不怕光粒，被二向箔压到也能活，但收入减半。单位数 = 星系数 + 在飞的战舰和殖民船 + 星舰 | 只能做一次 |

## 6. 灭亡和胜负

- 文明的星系全丢了：
  - 还有星舰：文明还活着（「星舰文明」），可以开着星舰找能殖民的星系重新定居。
  - 没有星舰：文明灭亡，它准备中和在飞的东西（战舰、殖民船、二向箔、黑域、广播）都消失。
- 胜负（暂定）：
  - 只剩你一个文明活着：你赢。
  - 你灭亡：你输（对局结束）。
  - 所有文明都灭亡（例如同时被二向箔压平）：没有赢家。
  - 整张星图都被压平，还剩两个以上文明（都已降维）：平局。
- 观战模式（平衡模拟用，5 个文明都由 AI 控制）：打到只剩一个文明或全图压平为止。

## 7. AI 怎么行动

AI 用和你一样的规则，每回合按下面的顺序挑能做的事，直到行动点用完或能量不够：

1. 二向箔再过 3 回合以内就会压到自己的星系（`AI_REDUCE_ALERT`）：先降维；能量不够就攒着，这回合什么都不做。
2. 只剩星舰：停在能殖民的星系上就定居；否则朝最近的、没去过的宜居星系移动。
3. 能量攒到 60 以上（`AI_FOIL_ENERGY`）、又知道一个还没压平的敌人：先降维，降维完成后朝最近的
   已知敌人发射二向箔（同时最多一片）。
4. 光粒射程内有已知敌人：没有恒星广播器就先建；有了就发光粒，能量不够就攒着。
5. 已知敌人都在射程外：派一艘战舰过去（同时最多一艘）；已经有战舰在路上，就广播那个坐标（每个坐标一次）。
6. 没有能打的目标时，依次尝试：造预警系统 → 被打中过就在母星投放黑域 → 被打中过就在有类木行星的星系建掩体
   → 被打中过就建星舰 → 朝最近的宜居星系派殖民船（同时最多一艘，派过的目标不再去）
   → 建采矿船（每回合最多一艘）→ 建戴森球（每回合最多一个）→ 没有反物质时造一个
   → 升级探测器、望远镜 → 朝随机方向探测。
