## 一句话

在 10×10×10 的星图里，各个文明藏起自己的位置，靠有方向的探测去找别人，
再用有方向或指定坐标的武器打击。恒星是实力的根本，也是被打击时损失的东西。

## 1. 舞台和身份

- 星图有 1000 个格子（10×10×10），一格大约 1 光年见方，最多一个星系。大约一半的格子有星系
  （单星最多，双星其次，三星最少），星系里有类地行星和类木行星；有宜居类地行星的星系可以殖民，
  有类木行星的星系可以建掩体。生成方法见 [原型现在的规则](current-rules.md)。
- 坐标用右手系，x、y、z 都是 0～9 的整数，z 轴是高度（朝上）。
- 星系的位置不公开。平时画面只显示网格、自己的星系和探测到的情报；只有在派殖民船时，
  才显示宜居星系（和它有几颗恒星），供选择方向。
- 一个人类玩家对 4 个 AI 文明，另外还有 15 个看不见的「隐藏文明」。
- **恒星总数决定实力**：
  - 恒星越多，每回合能量越多，但行动点越少（乱纪元：恒星多，环境不稳定）。
  - 能建几个戴森球也看恒星数。
  - 被光粒打中，恒星减一。

## 2. 两条基本规则

### 沿方向行动

除了建造，所有动作都是选一个方向打出去。

- 探测是圆锥：射电望远镜让圆锥张得更开，探测器让它伸得更远。
- 战舰攻击和光粒是圆柱：有方向，也有宽度。

### 指定坐标，提前准备

黑域、二向箔、广播指定一个坐标，要花几个回合准备，然后才生效。

### 选择发射源

殖民地多了以后，可以从自己的母星或任一殖民地中选一个作为打击的发射点。
发射点不同，方向和距离就不同，也决定了打击从哪里出发。

## 3. 一局的节奏（类似海战棋）

参考实体桌游「海战棋」：双方暗中摆放，轮流盲打，对方只告诉你打没打中。

1. **发展**：采矿、建戴森球、殖民，增加恒星数。
2. **探测**：朝一个方向发圆锥，发现的敌人坐标记进「已知坐标」。
3. **打击**：先选发射源，再选方式。
   - 战舰：沿方向飞，每回合 2 格，碰到敌人就停下攻击。
   - 光粒：圆柱范围，打中后对方少一颗恒星。
   - 二向箔：先在发射源准备几个回合，然后飞向目标坐标；到达后以那一格为中心压成平面，
     中心最扁，再逐渐向外扩散。第一片展开确定共同高度，后续打击也压到这一平面。
   - 单向箔：全图进入二维后可用，沿用准备和飞行流程；把 y 压到首次展开选定的共同 y，
     最终只剩沿 x 轴的直线。二维继续对战；已展开的空间坍缩在胜负出现后仍会完成。
4. **反馈**：每次打击后知道打没打中，结果记在一张只有自己能看的「敌情记录图」上
   （相当于海战棋里记录结果的竖板）。
5. **借刀杀人**：广播别人的坐标，可能引来隐藏文明替你出手。

## 4. 防守手段（由弱到强）

| 手段 | 作用 |
| --- | --- |
| 预警系统 | 抵消一次打击 |
| 反物质 | 拦截战舰攻击 |
| 类木行星护盾（掩体） | 光粒照样打爆恒星，但星系不会因此丢掉（见 [原型现在的规则](current-rules.md)） |
| 能量力场 | 待设计 |
| 黑域 | 困住战舰和光粒；投放需要几个回合 |
| 自身降维 | 第一次进入二维，抵挡二向箔；全图二维后可再次准备一维生存，抵挡单向箔。每次按单位数收费、需要几个回合、期间不能建造，收入再减半 |

### 自身降维的携带成本（2026-10-04 补充想法）

- 要带入二维的**已建造单位越多，自身降维消耗的能量越高**。
- 降维需要数个回合（时间单位）才能完成，期间不能建造。
- 具体能量公式、所需回合数仍待调；本条没有规定单位越多、所需回合也越多。
- 本次原型采用全部携带，已建成设施也计费；已有建造 / 升级先完成，再启动降维。
  计数范围见 [当前规则 §5](current-rules.md)，暂不增加部分携带选择，后续讨论见
  [E6](../open-questions.md#e6-自身降维的携带范围和成本)。

## 5. 设计方向

旧版是「找到你，一枪打死你」，新版是「找到你，一点点削弱你」：

- 光粒只打掉一颗恒星，被打的文明还有机会翻身。
- 大招要准备几个回合，对手有时间反应。
- 降维代价变高，不再是免死按钮。

预期效果：对局更长、来回更多，AI 来得及发展起来。

## 6. 和旧版的差异

旧版指已归档的 Python 版（`archive/python` 分支），也就是交接文档描述的规则。

| 话题 | 旧版 | 目标版本 |
| --- | --- | --- |
| 光粒范围 | 一条射线，打中路上第一个文明 | 圆柱，有宽度 |
| 光粒后果 | 直接消灭；有预警系统时损失一颗恒星 | 恒星减一 |
| 打击起点 | 固定是母星 | 可选母星或任一殖民地 |
| 二向箔 | 立即起飞，每回合 1 格 | 先准备几个回合，再起飞 |
| 黑域、广播 | 立即生效 | 准备几个回合后生效 |
| 自身降维 | 固定 40E，立即生效 | 按单位数收费，几个回合，期间不能建造 |
| 行动点和产能 | 只看母星类型 | 看恒星总数 |
| 反物质 | 攻击用的炸弹 | 拦截战舰 |
| 打击反馈 | 只有日志 | 敌情记录图 |
