# 科技树与中盘画面整理

提出：用户在项目对话中提出，2026-10-09。状态：已采纳。

## 原话

> 科技树设计成从左到右，箭头连线表示依赖层级关系先后。可以设成单独打开一个满屏界面。
> 主界面默认收起图例，减少画面遮挡。
> 减少广播的显示圈数。
> 中盘画面非常混乱，物件数、图例种数太多，颜色光晕很多，你认为如何改？可参照游戏领域最佳实践范式。照做。

## 采用的做法

V1：科技树独立全屏，按等级与前置关系从左到右排列；同级武器也在战舰右边。连线只取真实前置，选中节点突出相邻依赖；节点显示状态和价格，底部显示说明、等级条件与研究按钮，锁定节点仍可查看。窄屏滚动浏览，关闭回到原星图。

V2：主界面默认收起图例和全体视野；广播仅显示最近三条仍在图内传播的己方波前。三维是朝向镜头的单环示意半径，二维仍是平面圆，一维仍是带端点的线段。实际传播条数用摘要说明，全部目标保留但同坐标去重，目标使用空心框。

V3：默认概览保持己方、已知敌方与预警的层次，己方飞行单位统一蓝色、探索星系使用中性色，移除常驻星系光晕并减淡黑域填充；停泊舰队按星系聚合为数量。选中单位或行动页当前单位才展开航线，选中星系展开设施，悬停文字补充单位种类和设施数量；详细模式可展开所有航线、设施和敌方星系名称。敌方舰船情报、当前预警和打击方向始终保留。隐藏面板或切离行动页后不继续画瞄准预览。

这些都是显示方式调整，不改变单位数量、科技依赖、广播传播、视野、迷雾或打击规则。暂不对敌情做自动隐藏，也不改变待定的降维规则。
