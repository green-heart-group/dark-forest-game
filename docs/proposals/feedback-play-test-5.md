# 试玩意见：第五次（广播球、零维动画、降维武器的名字）

状态：已整理（2026-10-07）

E7F6 的原话（附了一张第 69 回合降到零维获胜时的截图），按意思分成 3 条，每条后面是整理结果。
第 n 条定下的决定编号是 F5.n，记在 [游戏设计 §14](../design/game-design.md#试玩意见定下的f)。

> 广播的球面影响视野
> 降为零维也是要有个小动画
> 一维宇宙的降维打击物叫做奇异点，二维宇宙的降维打击物叫做单向著，左下角都是显示的二向箔

1. 广播的球面挡住了视线。
   - 已改（只改画面）：原来自己发出的广播画成一个实心的半透明粉色球，一直扩大到星图外面很远；
     几次广播叠在一起，整张星图都被染成粉色。现在只画三个互相垂直的细圆圈，球面传出星图以后就不再画。
     被广播的坐标还是画粉色方块。
2. 降到零维要有个小动画。
   - 已改（只改画面）：有文明降到零维时，视角移到它的星系，整张星图（网格和所有标记）越缩越快地缩向那一点，
     快缩完时闪一下，最后只剩一个白色亮点。动画放 2 秒。游戏设计 §9 原来就写了「要先播完一维降到零维的动画」（T14），
     这次补上。回放跳到降维以后的回合时，直接画成一个点，不放动画。
3. 二维、一维里的降维武器，左下角日志都写成「二向箔」。
   - 原因：日志里的是预警系统的报告，不管飞来的是什么箔，都写「二向箔」。截图里的四条其实是隐藏文明早先发的二向箔，
     那时星图已经压平，它们到了也压不了什么，但还在飞、还在报。另外隐藏文明不管星图是几维，都只会发二向箔。
   - 已改：
     - 预警和看到的舰船按箔的种类叫名字：二向箔或单向著。已经没用的箔（星图全部压平以后的二向箔、
       压成直线以后的单向著）不再报警。
     - 隐藏文明按现在的维度出手：三维时发二向箔；二维时发单向著，目标挪到平面上；压成直线以后没有箔可发，只发光粒。
     - 奇异点在规则里不是飞出去的武器：一维的文明发射奇异点，是让自己降到零维、赢得对局（T14），
       所以不会出现在预警里。
   - 平衡模拟见 [现状](../status.md#平衡模拟的最新结果)。
