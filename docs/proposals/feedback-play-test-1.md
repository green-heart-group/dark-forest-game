# 试玩意见：第一次试玩新规则

状态：已整理（2026-10-06）

E7F6 的原话，每条后面是整理结果。第 n 条定下的决定编号是 F1.n，记在 [决定记录](../design/decision-log.md#试玩意见定下的f)。

开了全知者模式依然打不过 AI。

1. 初始星系应该随机选择，不要总在 (1,7,0)。
   - 已改：每局随机生成星图，种子写在日志第一行，加 `-- seed=种子` 可以重玩同一张。见 [原型现在的规则 §1](../design/current-rules.md#1-星图和星系生成)。
2. 请确认 AI 在自行探知或收到广播获取信息前，不知晓其他文明的位置和发展情况。
   - 查过：AI 只用自己看到的、听到广播的，以及大家都知道的东西（宜居星系的位置、二向箔展开的范围）。
     加了规则测试 `test_ai_only_knows_what_it_saw` 确认这一点。
3. 目前星图观感不够直观，己方与敌方单位可尝试用更明显的方式表示，与之相比每个坐标的星系状况图标、坐标轴线可以弱化；
   现在采用选点方式不易点到想要的坐标。
   - 已改：坐标轴、网格和恒星图标变淡；己方和敌方的单位、星系变大，星系加了光圈和名字；
     点格子时找离鼠标最近的格子；行动页可以直接输入 x、y、z 坐标。
4. 有鉴于实际游戏体验，同意将殖民船科技与星舰科技同步向上一级前移，玩家在探索不到其他文明时，可以先发展自己的殖民地。
   - 已改：殖民船改成 0 级（007，开局就有），星舰改成 I 级（106）。见 [游戏设计 §5](../design/game-design.md#5-科技树建造和调度)。
5. 目前初始能量产出太少，与矿石消耗途径相差过大，矿石达到 100 后能量还在个位数，考虑恢复原先的初始能量产出，
   所有类地行星均可提供 +2 能量产出。
   - 已改：每个星系 2E + 每颗恒星 1E，类地行星每颗 2E。能量多了以后 III 级升得太早，门槛从 30E 提到 60E
     （[游戏设计 §12](../design/game-design.md#12-写进设计时补的暂定做法)，[T22](../design/archive/decided-questions-2026-10.md#t22-写代码时补上的做法) 定了照这样做）。
   - 后来改了：能量见 F2.1，III 级门槛见 F2.3、E8（[决定记录](../design/decision-log.md)）。

「打不过 AI」的原因还没找到，记在 [路线图](../roadmap.md#下一步)，试玩后再看。
