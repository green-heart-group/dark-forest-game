# 黑暗森林 3D 桌游模拟器（旧 Python 版，已归档）

> **已归档，不再更新。** 新版本用 Godot 4 制作，在 `master` 分支。
> 这个分支只留作旧规则的对照，已知 bug 不修。

用 Python + Tkinter + Matplotlib 做的第一个版本。

## 运行

需要 [uv](https://docs.astral.sh/uv/)：

```
uv run python -m sj_dark_forest.main
```
